# Diffgloss v0.3 Architecture: Dual-Role Author/Auditor Engine + Tauri v2 Desktop App

> Date: 2026-11-24. Target: macOS (`.app` / `.dmg`) & Windows (`.msi`) desktop app + dual-model `Author Explains -> Independent Reviewer Audits Every Changed Line` protocol.

---

## 1. Core Architectural Upgrade (Phase A)

### Role A — Explainer (Configurable Mode)
1. **`author_cli` (Default when local coding agent is available)**:
   - Connects directly to the user's local **Claude Code CLI** (`claude -p --permission-mode plan [--resume <sid> --fork-session]`) or **Codex CLI** (`codex exec -s read-only`) so the authoring coding agent (with its session context and user subscription) drafts per-hunk explanations covering every changed line.
2. **`api_model` (Fallback / Explicit)**:
   - Uses Diffgloss's configured **Model A** (`deepseek`, `anthropic`, `openai`, `google`, `openai-chat`, `mock`) to explain hunks blind from diff + repo + declared intent.

### Role B — Independent Line-by-Line Auditor (Model B)
- Runs in a **strictly separate context** (recommended: different model family from Role A).
- Treats Role A's draft explanation as **`UNTRUSTED_AUTHOR_CLAIM`**.
- Audits **every changed `+`/`-` line** in every hunk and outputs an `audit` record:
  - `verified`: every changed line accounted for and explanation matches actual code logic.
  - `omission_detected`: author skipped specific changed lines -> lists exact `omitted_lines` highlighted in red/amber in the diff viewer.
  - `contradicted`: author explanation contradicts actual diff behavior -> pins `contradiction` note and demotes hunk to `unexplained`.
  - `pending` / `unexplained`: missing or unverified explanation.
- Runs parallel **Symmetric-Proof Specialists** in a clean context that **never** sees author explanations/answers.

### Performance & UX — Cache + SSE Progressive Streaming
- **Hunk-level content cache** (`.diffgloss/cache/<hunk_id>.json`): unchanged hunks hit disk cache in <5ms with zero repeated token spend.
- **SSE streaming endpoint (`GET /api/explain-stream`)**:
  - `T = 0.2s`: Deterministic diff, AST sub-hunks, collapsed noise, and built-in integrity flags render immediately.
  - `T = 5–20s`: Explainer streams per-hunk explanations live (`stage: explaining`, `done / total`).
  - `T = 15–45s`: Independent Line Auditor streams per-hunk verdicts live (`stage: auditing`, flipping badges to `✓ Audited`, `⚠ Lines Omitted`, or `✗ Contradicted`).

## 2. Desktop App Packaging (Phase B — Tauri v2)

- **Directory**: `desktop/` (keeps root npm/CLI package clean and zero-dep).
- **Rust Shell (`desktop/src-tauri/`)**:
  - Native macOS/Windows window using system WKWebView / WebView2 (~10–15 MB installer).
  - **Native Folder Drag-and-Drop (`tauri://drag-drop`)**: receives real filesystem paths (`/Users/.../repo`), validates git repo, and loads diff instantly via the local Diffgloss engine.
  - **Native Open Folder Picker** (`tauri-plugin-dialog`) & **OS Menu / Shortcuts**.
  - **Engine Sidecar Management**: spawns the compiled Diffgloss engine binary (`diffgloss-engine` built with `bun build --compile` or local Node/Bun fallback during dev) on a free loopback port (`127.0.0.1:<port>`), health-checks it, and terminates it cleanly on app exit.
- **Cross-Platform CI Release**: `.github/workflows/release-desktop.yml` builds macOS (`aarch64` / `x86_64`) and Windows (`x86_64`) installers automatically on `v*` tags.
