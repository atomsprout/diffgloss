Mechanical Citation Grounding

Separates structural grounding (citations_valid: exact line bounds & verbatim symbols) from semantic verification (judge_passed). Failed citations trigger 1x repair, then honest demotion to unexplained.

Multi-Language AST Sub-Hunks

Lexer-aware scope tracking across TypeScript, JavaScript, Python, Go, Rust, Java & C++ splits oversized hunks along real method/function boundaries so sneaky edits can't hide inside a 150-line diff.

30-SECOND SETUP

Start reviewing with clarity

Zero runtime dependencies. Works out of the box on Node 20+ and Bun 1.2+.

1. Launch Local Browser Workbench (No Env Vars Needed) 
git clone https://github.com/atomsprout/diffgloss.git
cd diffgloss
bun install && bun run build

# Opens interactive browser workbench on http://127.0.0.1:4317
# Click "📂 Repo / Commit" to pick any repo or commit, and "⚙ Models" to configure keys!
node dist/cli.js ui
2. CI Gate, SARIF & MCP Server 
# Full blind-first explain + semantic judge + symmetric-proof review
node dist/cli.js explain main..HEAD --provider deepseek --judge --review \
  --sarif-out .diffgloss/out.sarif

# Enforce zero unexplained hunks in CI (exit code 2 on violation)
node dist/cli.js validate .diffgloss/ledger.json --max-unexplained 0

# Start MCP stdio server for Claude Code / Codex / Cursor
node dist/cli.js mcp
