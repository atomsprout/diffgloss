30-SECOND SETUP

Start reviewing with clarity

Install the native macOS/Windows app — or run straight from CLI with Node 20+ or Bun 1.2+.

1. Native Desktop App (Build or Download v0.3.0) 
# Or download prebuilt .dmg / .exe from GitHub Releases (v0.3.0)
git clone https://github.com/atomsprout/diffgloss.git
cd diffgloss/desktop
bun run build:all

# Launch native macOS app & drag any Git repo folder onto the window!
open src-tauri/target/release/bundle/macos/Diffgloss.app
2. Dual-Role CLI, Line Auditor & Browser Workbench 
# Launch zero-env-var local browser workbench (configure Role A & B in-page)
node dist/cli.js ui

# Dual-role CLI: Author Agent (Codex/Claude) explains -> Independent Line Auditor checks every line
node dist/cli.js explain main..HEAD --explainer-mode author_cli --audit --review --serve

# Enforce zero unexplained hunks in CI (exit code 2 on violation)
node dist/cli.js validate .diffgloss/ledger.json --max-unexplained 0
